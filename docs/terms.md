# 使用条款草案

## 状态

本文件是项目级发布草案，不构成法律意见。公开发布者必须补充实际主体、辖区、联系方式、生效日期和适用的争议条款，并取得必要审阅。

## 服务说明

Ask User Question 提供结构化澄清问题卡片，帮助 Assistant 在关键选择不明确时向用户收集答案。它不执行确认题中描述的业务动作，也不提供平台级暂停、保证停止或 agent suspend/resume。

## 可用性

功能依赖 ChatGPT / Codex 产品表面、工作区策略、MCP 连接、网络和模型指令遵循。服务可能中断、变化或产生不符合预期的模型行为；用户应在重要操作前复核输出。

## 合理使用

不得利用服务绕过平台政策、收集无授权数据、发送违法内容、攻击基础设施或冒充他人。部署者可以为安全、容量或合规采取限流、暂停或终止措施。

## 第三方服务

ChatGPT、Codex、托管平台和其他基础设施受各自条款和隐私政策约束。本项目草案不替代这些第三方条款。

## 责任与变更

责任限制、保证否认、终止、适用法律和争议解决必须由实际发布主体确定。条款或功能发生重大变化时，应更新公开页面和插件版本材料。
