# 支持说明

## 获取帮助

公开发布前，发布者应提供一个持续可用的 HTTPS 支持页面和联系渠道。支持请求建议包含：

- 插件版本和客户端；
- 可见模型标识与工作区类型；
- 发生时间和复现步骤；
- 工具是否被发现、卡片是否展示、答案是否发送；
- 脱敏后的错误信息。

不要提交访问令牌、完整聊天记录或未脱敏的敏感答案。

## 常见检查

1. 检查服务 `GET /` 和 `/mcp` 是否可访问。
2. 确认 `APP_ORIGIN` 与公网独立 HTTPS origin 一致。
3. 确认 `.app.json` 的 ID 属于当前目标工作区的已注册连接。
4. 服务或 metadata 更新后刷新连接并新建对话。
5. 区分工具调用、UI 渲染、`ui/message` 发送和模型停止等待四个事件。

## 安全问题

公开发布者应提供独立的安全报告渠道、响应时限和披露政策。报告中只包含复现所需的最少数据。
