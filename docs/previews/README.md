每版均展示填写中和提交后的问答摘要。预览为方便比较预填“多选”和详情，正式产品仍不默认选择答案。原型中的“重新体验预览”只用于设计演示。

## B 版完整对话流

打开 [B 版聊天预览](chat-flow.html)，或访问当前预览服务的 `http://localhost:8790/chat-flow.html`。

- 上下滚动整页查看历史消息；底部输入栏固定，无卡片内部滚动。
- 顶部可跳到历史、回到问题或重新体验；离开底部后出现回到最新消息按钮。
- 卡片默认不选择答案，选中后显示浅灰高亮和详情输入。
- 点击提交或详情中按 Enter，卡片收起为题目与答案，并追加预设的模拟助手回复。
- 也可直接从底部回复；未提交的卡片以该文字收起，后续消息继续追加到对话中。
- 所有对话均为本地模拟，刷新或重新体验会清空本次演示输入。

截图：[填写状态](chat-flow.png)、[提交后](chat-flow-submitted.png)、[手机布局](chat-flow-mobile.png)。

需要重新启动时，在仓库根目录执行：

```bash
python3 -m http.server 8790 --bind 0.0.0.0 --directory docs/previews
```

## 待落实到正式 UI 的交互

- 扩大选项行的点击区域，覆盖编号、文字和行内留白。
- 选中后展开该项的补充详情；切换选项保留草稿。

- 成功发送后收起为题目和答案；发送中防重复，失败保留表单并允许重试。

## 代码检查发现

当前 `QuestionCard.tsx` 的选择事件绑定在标签内，外层选项容器的留白和禁用详情框不能触发选择，可能造成点击不灵的感觉；真实宿主中的偶发点击问题仍需复测。

当前 `App.tsx` 使用 `main` 和 `type="button"`，没有表单提交或输入框 Enter 处理；发送成功后仅禁用控件，保留全部表单。
