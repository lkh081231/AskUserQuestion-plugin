# UI 风格预览

日期：2026-09-22。此阶段提供样式和交互原型，等待用户选择后修改正式 UI。

## 查看预览

用浏览器打开 [交互预览](ui-directions.html)。页面独立运行，不连接 MCP，不向聊天发送消息。

- A：经典分隔线，最接近用户参考图。
- B：选中项浅灰高亮，增强选中反馈。
- C：紧凑列表，减少纵向占用。

每版均展示填写中和提交后的问答摘要。预览为方便比较预填“多选”和详情，正式产品仍不默认选择答案。原型中的“重新体验预览”只用于设计演示。

## 待选定后实施的交互

- 扩大选项行的点击区域，覆盖编号、文字和行内留白。
- 选中后展开该项的补充详情；切换选项保留草稿。
- 详情输入中按 Enter 提交，Shift + Enter 换行；中文输入法确认选字不提交。
- 成功发送后收起为题目和答案；发送中防重复，失败保留表单并允许重试。
- 保留四种题型、必填校验、Other 和选项补充说明。原型只演示单选，不代表完整功能验收。

本次优先预览摘要收起方案；没有实现或验证关闭宿主卡片的接口。

## 代码检查发现

当前 `QuestionCard.tsx` 的选择事件绑定在标签内，外层选项容器的留白和禁用详情框不能触发选择，可能造成点击不灵的感觉；真实宿主中的偶发点击问题仍需复测。

当前 `App.tsx` 使用 `main` 和 `type="button"`，没有表单提交或输入框 Enter 处理；发送成功后仅禁用控件，保留全部表单。

## 验证范围

预览通过 Chromium 检查三版的行内留白点击、Enter 提交、Shift + Enter 不提交、模拟输入法事件不提交、Other 空白校验、摘要收起及重置；检查 390px 窄屏没有横向溢出。

预览通过 Markdown 结构、本地链接和 `git diff --check` 检查。正式 UI 尚未修改；未执行真实 ChatGPT 验收，也未将预览检查计入产品验收结果。
