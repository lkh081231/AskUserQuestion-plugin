## B 版完整对话流

打开 [B 版聊天预览](chat-flow.html)，或访问当前预览服务的 `http://localhost:8790/chat-flow.html`。

- 提问面板与输入框位于同一个底部区域，两者间距为 8px。聊天记录独立滚动，不改变面板和输入框的屏幕位置。
- 默认展示多题，可在顶部切换单题。多题每次只显示一题，右上角显示 `1 / 3` 和前后导航，回退保留答案及详情草稿。
- 前面的题目按 Enter 或点击“下一题”确认当前答案并前进；最后一题按 Enter 或点击“提交全部”统一提交。单题按 Enter 直接提交。
- 卡片默认不选择答案，选中后显示浅灰高亮和详情输入。示例覆盖单选、多选和文本题，必填为空时定位到待填写题目。
- 提交后底部提问面板消失，聊天记录中保留一个圆角边框的摘要：每题灰色问题在上、深色答案在下，不再展示选项、按钮和分页。
- 顶部可跳到历史、回到当前问题或重新体验；离开底部后出现回到最新消息按钮。
- 小屏幕上，当前题目过长时允许选项区域内部滚动，标题、翻页和提交控件仍可见。
- 也可直接从底部回复；原型将自由文本原样收起为回复摘要，不尝试解析成各题答案。
- 所有对话均为本地模拟，切换模式、刷新或重新体验会清空本次演示输入。

## 待落实到正式 UI 的交互

- 扩大选项行的点击区域，覆盖编号、文字和行内留白。
- 选中后展开该项的补充详情；切换选项保留草稿。
- 单题和多题最后一题的详情输入按 Enter 提交；前面的题目按 Enter 前进。Shift + Enter 换行；中文输入法确认选字不提交。
- 成功发送后收起为题目和答案；发送中防重复，失败保留表单并允许重试。
- 保留四种题型、必填校验、Other 和选项补充说明。预览覆盖单选、多选和文本题，不代表完整功能验收。

本次优先预览摘要收起方案；没有实现或验证关闭宿主卡片的接口。

## 代码检查发现

当前 `QuestionCard.tsx` 的选择事件绑定在标签内，外层选项容器的留白和禁用详情框不能触发选择，可能造成点击不灵的感觉；真实宿主中的偶发点击问题仍需复测。

当前 `App.tsx` 使用 `main` 和 `type="button"`，没有表单提交或输入框 Enter 处理；发送成功后仅禁用控件，保留全部表单。
