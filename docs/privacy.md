# 隐私说明草案

## 适用范围

本草案描述 Ask User Question `0.1.0` 的仓库实现。公开发布者必须补充主体名称、联系方式、生效日期、部署平台及其真实日志/保留策略，并由有权人员审阅后托管为公开 HTTPS 页面。

## 处理的数据

- MCP 服务接收 Assistant 生成的标题、问题、选项和说明，以便校验并返回卡片数据。
- 用户在卡片中填写的答案由 MCP Apps UI 通过 `ui/message` 直接发送给聊天宿主；本项目服务没有提交答案的独立工具或答案数据库。
- 运行基础设施可能处理 IP、时间、请求头、错误和性能等元数据，范围取决于实际托管、代理与监控配置。

## 使用目的

数据仅用于展示澄清问题、把用户答案送回当前对话、保障服务运行和排查错误。实现不请求完整聊天历史，不尝试重建对话，不将答案用于广告或独立画像。

## 保存与共享

仓库实现不持久化问题或答案。部署者应关闭请求体和原始敏感载荷日志，定义并披露基础设施日志保存时间。若云平台、反向代理或监控供应商作为处理方接触数据，发布者必须列明并配置适当协议。

## 安全

生产环境应使用 HTTPS、访问控制、最小日志、限流、依赖更新和密钥管理。当前版本没有业务账号系统或自定义 OAuth；这不代表任意公开部署天然安全。

## 用户选择

用户可不使用卡片并直接在聊天中回答，也可改变或取消原任务。发送失败时，卡片只显示可选择文本供用户手动复制，不调用系统剪贴板。

## 联系与变更

发布前填写运营者联系渠道和政策 URL。数据处理行为变化时，应更新本说明、manifest 和版本记录，并在需要时重新取得审核。
